## Project Architecture & Pipeline

The project follows a structured machine learning data preprocessing and classification pipeline:

* **Missing Data:** Handles missing or null values in the dataset using imputation techniques (mean, median, mode) or by dropping incomplete rows/columns.
* **Outlier Treatment:** Detects and handles extreme values or outliers using methods like IQR or Z-score to prevent skewed model performance.
* **Feature Engineering:** Creates new meaningful features from existing data and transforms variables to improve model accuracy and learning.
* **Label Encoding:** Converts categorical (text-based) data into numerical formats so that machine learning algorithms can process them.
* **Scaling:** Standardizes or normalizes the range of numerical features (e.g., using StandardScaler or MinMaxScaler) for balanced model training.
* **PCA (Principal Component Analysis):** Performs dimensionality reduction to select essential features while retaining optimal variance and information.
