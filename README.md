# Sports Balls Multiclass Image Classification

## IT2011 - Artificial Intelligence and Machine Learning project
Welcome to the Sports Balls Multiclass Image Classification project, a fully-integrated system designed to classify sports balls using machine learning as a course Project for IT2011 - Artificial Intelligence and Machine Learning.

This project integrates different modules to provide a seamless platform for image processing and classification.
